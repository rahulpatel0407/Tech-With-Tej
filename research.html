Internship project · July–October 2026

Web Log Anomaly Detection and Security Monitoring — NRSC, ISRO

During my internship at the National Remote Sensing Centre (NRSC), ISRO, I worked on an AI-assisted pipeline for web-log anomaly detection and security monitoring. The project connected Apache access/error logs with Filebeat, Logstash, Elasticsearch, and Kibana, and explored Isolation Forest and Local Outlier Factor (LOF) for flagging unusual patterns. A Python inference service using FastAPI and a monitoring dashboard helped present model results.

The public summary intentionally excludes internal logs, network details, and other confidential information. It describes project work and does not claim that the system was deployed into production.

Applied AI · Agritech

AgriHealth AI — Crop and Plant Advisory

AgriHealth AI is an agritech project designed to bring crop-health support and practical advisory tools together. Planned and demonstrated capabilities include crop-disease assistance, weather alerts, soil/crop recommendations, fertilizer guidance, government-scheme information, and an AI-powered farmer assistant.

The project work draws on computer-vision approaches such as YOLO/CNN, a web dashboard, geospatial tools, and IoT sensor prototypes. AgriHealth AI received first prize at IBM Hackathon 2026 and was presented at AI Summit Bihar 2026.

QRLink explores offline file transfer using animated QR frames, with adaptive encoding and error-recovery ideas intended to improve reliability when frames are missed or corrupted.
